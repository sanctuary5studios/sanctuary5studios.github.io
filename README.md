# sanctuary5studios.github.io
Official site for Sanctuary Five Studios (sanctuaryfivestudios.com), a technology company.

Plain static HTML on GitHub Pages, no build step.

- `index.html` Home
- `games.html` 01 Mobile Games & Apps (Snuggle Sanctuary)
- `ai.html` 02 AI Guidance & Setup
- `software.html` 03 App & Software Development
- `process.html` 04 Process & Systems Improvement
- `investors.html` Investor enquiries
- `contact.html` Contact form (opens the visitor's email app, pre-filled)
- `testers.html`, `animation.html`, `privacy.html`, `account-deletion.html` Snuggle Sanctuary pages
- `assets/site.css`, `assets/site.js` Shared styles and interactions
