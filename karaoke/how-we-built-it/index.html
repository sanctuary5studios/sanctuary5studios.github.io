How we built Sanctuary Five Studios Karaoke

Sanctuary Five Studios Karaoke was designed in-house as an independent, offline-first alternative to subscription karaoke software.

A written plan first

We started from a written specification and a feature research document.

Built as a Windows desktop app

It was built as a Windows desktop app, with its own audio engine (two decks, a mixer and live key changing), CDG graphics and synced-lyrics renderers, a singer rotation system, and a separate audience display.

Tested like it's show night

It was tested with automated tests and full-app checks that launch the real program, play every supported format, and exercise the singer rotation, the audience screen and the purchase flow.

Made ready to sell

We then gave it the Sanctuary Five Studios identity (splash screen, colours and icon), removed every GPL component so it could be sold commercially, added offline purchase keys with a 10-minute demo, and wrote a privacy policy that the app enforces by blocking all internet access.
